# 冷树选区工具

<img src="assets/icon.png" alt="冷树选区工具" width="96" />

在 Photoshop 当前图层上选择人物、身体部位、裸露皮肤与衣物颜色。作者：**暖树**。

**独立测试版，核心源码暂不公开，不属于 Dreamer 正式插件。** 仓库提供安装包、校验、模型资源和教学。

## 下载与安装

**[下载最新安装包](https://github.com/manba-pan/nuanshu-selection-lab/releases/latest)** · **[完整使用教学](QUICKSTART.md)**

当前程序：`LengShu-Selection-Tool-0.4.0-Windows-x64-Setup.exe`。无需预装 Python、Anaconda 或 CUDA。

1. 保存PS作品后安装。安装器自动发现运行中的PS、注册表和常见目录；多版本可选择，也可手动指定。
2. 安装时可选模型目录，启动页还能改路径、复用已有模型。程序内已保存的位置优先，不自动搬动或删除旧模型。
3. 重启PS。打开「首次准备与教学」，查看硬件推荐，保存设备与模型方案，再准备模型。
4. 在PS「增效工具 → 冷树选区工具」读取单个图层，提交任务，检查后写回原文档选区。

建议Windows10/11 x64、PS2026、32GB以上内存；首次至少预留25GB磁盘，多个方案共存需要更多空间。本机验证：48GB内存、RX9070XT、PS27.7；其他组合仍需实测。

## 设备与模型

启动页检测专用显存。8GB档推荐0.4B轻量GPU方案；更充裕显存可选1B混合精度。显卡使用DirectML路径，兼容NVIDIA/AMD，具体模型不支持时会回退CPU并显示原因。RTX5060尚未实机验证。

| 方案 | 文件合计 | 说明 |
|---|---:|---|
| 轻量GPU / CPU | 3.35GB | 0.4B人体解析及辅助模型 |
| GPU高精度1B | 5.49GB | 混合精度，敏感运算保留FP32，需留显存余量 |
| 高精度1B FP32 | 8.43GB | CPU或更大显存可选方案 |
| 原完整双模型 | 9.24GB | 0.4B与1B，兼容已有完整模型 |
| 实验5B INT8 / CPU | 7.72GB | 单任务；现有对照未证明优于1B，不默认推荐 |

合计包括BiRefNet、GroundingDINO与SAM2.1。已有有效文件会复用。GPU1B新权重约2.94GB：已有原1B FP32可本地转换，不修改原文件；否则从本仓库固定模型资源Release分段下载并校验。第三方模型遵循原始许可。

## 精度与任务页面

- 颜色可选“材质颜色／严格色值”。材质模式恢复有连续性证据的内部反光，保守排除皮肤和明显白色拼接；完全过曝和复杂边界仍需人工修正。
- 每次提交形成独立快照。计算中可以继续读取、导入、调参和排队，支持批量提交、取消、结果切换与刷新恢复。
- 最多2个任务推进准备/保存，GPU大模型阶段依次使用设备，避免显存叠加。后台重启保留完成结果，未完成任务标记取消，不自动重复运行。
- 优化画布缩放和平移，移除每帧逐像素JS合成。
- PS写回核对文档、图层、历史、坐标与读取标识。外部编辑后需重新读取；只改选区，不自动保存。
- 支持8位/16位RGB/RGBA单层。16位仅转换分析副本，原稿位深不变；暂不支持32位或多层同时读取。

## 下载慢时

普通HF模型可选官方、HF-Mirror第三方镜像或自动模式。新大文件最多4路续传，显示速度和当前文件剩余时间；可暂停后换源继续，旧版未完成文件保留单连接续传。新GPU衍生权重来自GitHub，不经过HF镜像。

## 隐私与许可

推理在本机进行，不上传照片。模型下载按选择访问HF、第三方镜像或GitHub。图片副本、结果、日志与设置默认位于 `%LOCALAPPDATA%\NuanShu\SelectionLab`；关闭面板不会自动清理，卸载默认保留数据与模型。

下载后执行 `Get-FileHash .\LengShu-Selection-Tool-0.4.0-Windows-x64-Setup.exe -Algorithm SHA256`，与同一Release校验文件核对。测试版未做商业代码签名，不要关闭系统防护。

核心原生编译、界面资源加密、PS桥接混淆增加逆向成本，不能保证无法逆向。AI结果需要人工复核，保留原稿。模型与运行库适用各自原始许可，原文随应用和模型资源提供。
