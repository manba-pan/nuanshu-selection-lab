# 冷树选区工具

<img src="assets/icon.png" alt="冷树选区工具" width="96" />

在 Photoshop 当前图层上选择人物、身体部位、裸露皮肤与衣物颜色。作者：**暖树**。

**独立测试版，核心源码暂不公开，不属于 Dreamer 正式插件。** 仓库提供安装包、校验、教学及许可允许分发的模型资源；不公开开发源码、用户图片或本机数据。

## 下载与安装

**[下载最新安装包](https://github.com/manba-pan/nuanshu-selection-lab/releases/latest)** · **[完整使用教学](QUICKSTART.md)**

当前程序：`LengShu-Selection-Tool-0.6.1-Windows-x64-Setup.exe`。轻快、均衡及 DINO + SAM 2 方案使用内置 ONNX 运行时，无需预装 Python、Anaconda 或 CUDA。

0.6.1 修复常用方案卡片与下方配置显示不一致的问题。下拉框明确标为“人体解析模型”；完整方案另外显示组成、总量、缺失文件及运行时。均衡、SAM 3 和细节优先会共用 1B 人体模型，但对象识别与边缘组件不同。选择方案后先查看配置，再保存并下载缺少的模型。旧版可直接覆盖更新，无需先卸载；已下载模型和模型目录设置保留。新增对象画笔，保留普通画笔与矩形对象选取。

1. 保存PS作品后安装。安装器自动发现运行中的PS、注册表和常见目录；多版本可选择，也可手动指定。
2. 安装时可选模型目录，启动页还能改路径、复用已有模型。程序内已保存的位置优先，不自动搬动或删除旧模型。
3. 重启PS。打开「首次准备与教学」，查看硬件推荐，保存设备与模型方案，再准备模型。
4. 在PS「增效工具 → 冷树选区工具」读取单个图层，提交任务，检查后写回原文档选区。

建议 Windows 10/11 x64、PS 2026、32 GB 以上内存；首次建议预留 25 GB 磁盘，多个模型方案及独立运行时共存需要更多空间。本机验证：48 GB 内存、RX 9070 XT、PS 27.7；其他组合仍需实测。

## 设备与模型

启动页按运行设备、内存、专用显存与运行时状态提供建议。8 GB 显卡优先“轻快”；可用 DirectML、至少 12 GB 显存及 24 GB 内存时优先“均衡”。CPU 优先轻快，不设置 10–20 秒目标。推荐不会自动下载或替你保存配置。

| 常用方案 | 全新 GPU 配置模型容量 | 用途 |
|---|---:|---|
| 轻快 | 约 2.87 GB | Sapiens2 0.4B + FP16 人像边缘，减少下载与内存占用 |
| 均衡 · 日常推荐 | 约 5.00 GB | Sapiens2 1B 混合精度 + FP16 人像边缘 |
| SAM 3 对象增强 | 约 8.45 GB | 在均衡组件上加入 SAM 3，复杂服饰按需使用 |
| 细节优先 | 约 9.32 GB | SAM 3、人体翻转增强、FP32 人像与 ViTMatte 边缘细化 |

容量为模型文件总量，不含程序、下载临时文件与独立运行时；CPU 轻快保留 FP32 人像，约 3.35 GB。各方案共用 SAM 2.1、GroundingDINO 等组件，已校验文件只保存一份；实际待下载量以页面为准。1B FP32、旧双模型、DINO + SAM 2 增强和 5B INT8 CPU 研究选项均保留。Qwen3-VL 仅属性理解研究，不自动参与选区。

**SAM 3 与 ViTMatte 的独立 PyTorch 运行时及编译 worker 不包含在本次普通安装包中，也不会随模型下载自动安装。** 仅下载权重不能使它们运行，须另行配置与硬件匹配的运行时，并完成本机验证。尚未准备该环境的用户先使用轻快、均衡或 DINO + SAM 2；页面区分“权重已下载”和“运行时可用”。本机 AMD ROCm 验证不代表其他 NVIDIA/AMD 配置均可直接使用。

### 速度参考

0.6.0 实测：RX 9070 XT 16 GB / 48 GB 内存、两张约 3200 万像素照片、白色衣物目标，轻快 **16.16–20.40 秒**，均衡 **17.39–24.10 秒**，SAM 3 **28.62–28.85 秒**；细节优先在其中一张为 **61.15 秒**。每张图使用新会话，包含生成及蒙版保存，不含 PS 读取、写回、排队与程序首次启动。照片导入另约 3–5.5 秒。

10–20 秒是配置足够时日常方案的优化目标，不能保证每张图或每种显卡达到。CPU 不适用上述显卡耗时；复杂图像、首次加载和 PS 占用可能增加等待。样本耗时不是准确率分数，RTX 5060 等其他设备仍需各自实测。

## 精度与任务页面

- 颜色可选“材质颜色／严格色值”。材质模式恢复有连续性证据的内部反光，保守排除皮肤和明显白色拼接；完全过曝和复杂边界仍需人工修正。
- 对象画笔（J）：沿目标内部涂一笔，松开后自动识别并补选或减选；采用现有 SAM 2.1，无需另加模型。识别失败或取消保留原选区；普通像素画笔和矩形对象工具继续可用。
- 每次提交形成独立快照。计算中可以继续读取、导入、调参和排队，支持批量提交、取消、结果切换与刷新恢复。
- 最多2个任务推进准备/保存，GPU大模型阶段依次使用设备，避免显存叠加。后台重启保留完成结果，未完成任务标记取消，不自动重复运行。
- 优化画布缩放和平移，移除每帧逐像素JS合成。
- PS写回按读取标识自动定位原文档和原图层，新增或切换其他图层无需重新读取。原层删除或原文档关闭时拒绝写回，原层位置、范围或画布尺寸改变后需重新读取；只改选区，不自动保存。
- 支持8位/16位RGB/RGBA单层。16位仅转换分析副本，原稿位深不变；暂不支持32位或多层同时读取。

## 下载慢时

普通 HF 模型可选官方、HF-Mirror 第三方镜像或自动模式。新大文件最多 4 路续传，显示速度和当前文件剩余时间；可暂停后换源继续。SAM 3 使用固定版本的 ModelScope 来源；FP16 人像使用 ModelScope，备用 Hugging Face；1B 混合精度权重来自 GitHub，已有 FP32 时可本地转换。不同组件的下载来源以页面所示为准，HF 镜像选项不改变所有组件的来源。

## 隐私与许可

推理在本机进行，不上传照片。模型下载按所选组件访问 HF、ModelScope、第三方镜像或 GitHub。图片副本、结果、日志与设置默认位于 `%LOCALAPPDATA%\NuanShu\SelectionLab`；关闭面板不会自动清理，卸载默认保留数据与模型。

下载后执行 `Get-FileHash .\LengShu-Selection-Tool-0.6.1-Windows-x64-Setup.exe -Algorithm SHA256`，与同一 Release 校验文件核对。测试版未做商业代码签名，不要关闭系统防护。
